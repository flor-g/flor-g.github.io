# The Need for a Scale

Flora Gu

---

It is easy to show that for every natural number \(n\), \(\{0, 1\}^n\) bijects \(\mathcal{P}([n])\). However, this correspondence does not hold for every real number \(r\). In fact, a segment of \(\mathbb{R}\) as small as \((0,1)\) is as big as \(\mathbb{R}\) itself (that is, there exists a bijection \((0,1) \leftrightarrow \mathbb{R}\)), so even \((0,1)\) is bigger than \(\mathbb{N}\). Now consider any formal or natural language: there is a finite amount of tokens available for each given position in a string, much like \(\{0, \dots, n\}^m\) where \(n\) and \(m\) are finite natural numbers. Assuming reality is uncountable (which the Bekenstein bound may challenge), therefore there does not exist a surjective function from a string of a finite length to reality. Thus, to apply a language to reality, we need real-numbered scales of the form \((0,1)\) as an interface between the infinite and the finite, such that the cartesian product \((\text{Language} \times \text{Scale})\) has a function to reality.

Two objections to the argument above can arise via the Bekenstein bound and Löwenheim–Skolem. As for the former, the objection would then move the tension to what specifies the bounded region (and by what principle is a region referred to by a string bounded at all?). As for the latter, I say this is not a real objection but an inquiry into how the resolution of a scale works.
